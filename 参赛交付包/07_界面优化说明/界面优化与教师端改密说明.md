## 一、先说结论：为什么你「找不到修改口令的地方」

上一版虽然把改密面板写进了 HTML，**但整个教师端的所有按钮都没有绑定事件**——根因在启动环节：

**`app.js` 的 `DOMContentLoaded` 启动链里，从头到尾没有调用 `setupTeacher()`。**

```
window.addEventListener("DOMContentLoaded", ()=>{
  setupTabs();  setupDiagnosis();  setupPosture();  setupStudent();
  setupAssistant();  initSandbox();  initTeam();  renderChatLocal();
  applyRoleMode();          // ← 缺少 setupTeacher();
});
```

后果是：登录按钮点不动、二级分区切不了、改密按钮无响应。所以「登录后找不到改密入口」不是排布问题，而是**功能根本没接上**。这次先把它补上了，再做的界面优化。

## 二、改动清单（位置 / 原因 / 实现方式）

### A. 教师端功能修复

| # | 位置 | 原因 | 实现方式 |
|---|---|---|---|
| A1 | `app.js` 第 9 节「启动」的 `DOMContentLoaded` 回调 | `setupTeacher()` 从未被调用，教师端全部交互失效 | 在 `renderChatLocal();` 之后补 `setupTeacher();` |
| A2 | `app.js` `setupTeacher()` | 登录后应立即能找到安全设置入口 | 重构为「工具条 + 二级分区 + 头像菜单」三层结构 |
| A3 | `index.html` `#teacherWorkspace` | 原结构是一长条平铺，改密面板淹没在顶部 | 拆为 4 个分区：**学情总览 / 题库编辑 / 系统与 AI / 成效与推广**，配 `#twTabs` 二级导航切换 |

### B. 修改口令功能（头像下拉菜单）

**入口位置**：教师端解锁后 → 右上角**用户头像（紫色渐变圆标「教」）** → 点击展开下拉菜单 → **🔑 修改口令**。

同时在「⚙️ 系统与 AI」分区的口令卡片里保留了第二个入口（`#btnChangePin2`），两条路径都能开。

| 项目 | 位置 | 实现 |
|---|---|---|
| 头像触发器 | `index.html` `#acctTrigger` | 圆形头像 + 姓名 + 下拉箭头，`aria-expanded` 同步状态 |
| 下拉菜单 | `index.html` `#acctDropdown` | 菜单项：修改口令 / 账户与安全 / 系统与 AI 设置 / 锁定退出（红色危险项） |
| 展开收起 | `app.js` `setAcct(open)` | 点触发器切换；点页面空白处自动收起；`Esc` 关闭；点任意菜单项自动收起 |
| 口令弹窗 | `index.html` `#pinModal` | 遮罩 + 卡片，点遮罩 / 取消 / `Esc` 均可关闭 |

**校验规则（全部实装并通过测试）**

| 校验 | 行为 |
|---|---|
| 原口令正确性 | 与本机当前口令比对，不一致则红色提示「✕ 原口令不正确，无法修改。」 |
| 最小长度 | 新口令 ≥ 4 位，否则「✕ 新口令至少 4 位。」 |
| 不可与原口令重复 | 新增规则，防止「改了等于没改」：「✕ 新口令不能与原口令相同。」 |
| 两次输入一致性 | 不一致则「✕ 两次输入的新口令不一致。」 |
| 强度要求 | 三段式强度条实时评估：<br>**弱**＝仅满 4 位；**中**＝≥6 位且字母+数字；**强**＝≥8 位且字母+数字 |
| 实时校验清单 | 弹窗内四条规则（原口令正确 / 至少 4 位 / 与原口令不同 / 两次一致）实时打勾 ✓ 打叉 ✕ |
| 明文切换 | 每个输入框右侧 👁 按钮可切换明文 / 密文 |
| 成功反馈 | 绿色提示「✓ 口令已更新（强度：强）。正在返回登录页…」，1.1 秒后自动退出到登录页，**必须用新口令重新解锁** |
| 忘记口令 | 登录页直接给出恢复命令 `localStorage.removeItem('hsm_teacher_pin_v1')`；「系统与 AI」分区还有「恢复默认口令」按钮 |
| 存储方式 | 存于本机浏览器 `localStorage`，不上传云端 |

### C. 界面与布局优化

| # | 位置 | 原因 | 实现方式 |
|---|---|---|---|
| C1 | `index.html` 主导航 `nav.tabs` | 10 个 Tab 一字排开、无逻辑分组，教师端还夹在学生功能中间 | 按 **`学习主线` / `实训探索` / `教学管理`** 三组重排，组间加竖线分隔 `.tab-sep`；教师端移到最右 |
| C2 | `index.html` 新增 `.crumb` 面包屑 | 页面深、只有 Tab 高亮，用户不知道自己在哪 | 面包屑显示 **首页 / 分组 / 当前页 + 一句话定位**，`updateCrumb()` 随 Tab 切换同步 |
| C3 | `app.js` 新增 `VIEW_META` + `updateCrumb()` | 导航需要单一数据源 | 一张表维护 10 个视图的分组/名称/描述，Tab 切换时统一更新 |
| C4 | `styles.css` 新增「v7 视觉统一层」 | 标题、间距、卡片规格在多处不统一 | 定义间距令牌 `--sp-1~6`、字阶 `--fs-xs~xl`；统一 `.panel` 内边距 20/22、H1 16px / H2 15px / 说明 13px / 辅助 12px |
| C5 | 同上的 `.zone-primary` / `.zone-secondary` | 主、次操作区没有视觉区分 | 主操作区用品牌蓝浅渐变底 + 蓝色描边 + 深蓝标题；次操作区保持白卡。已应用到题库编辑（主）与其列表（次） |
| C6 | 同上「组件统一」 | 按钮、输入框、卡片圆角不统一 | 统一操作按钮最小高度 34px、卡片圆角 16px、栅格间距统一为 `--gap-md`(18px) |
| C7 | `index.html` 教师端顶栏 | 原来「修改口令」「锁定退出」是普通按钮，层级与 breadcrumb 混淆 | 改为头像下拉菜单，把账户相关操作收拢到「用户域」，工具条只留状态 |
| C8 | 同上，新增「账户与安全」菜单项 | 用户不知道口令存在哪、怎么找回 | 点击后自动跳到「系统与 AI」分区并**呼吸高亮**口令卡片（`.flash-card` 动画 1.6s） |

## 四、给你的操作提示（录制视频前建议先看）

1. **必须刷新并清缓存**：按 `Ctrl+F5`。若本机之前存过自定义口令，可在控制台执行 `localStorage.removeItem('hsm_teacher_pin_v1')` 回到默认 `anatomy2026`。
2. 教师端路径现在是：**🏫 教师端 → 输入默认口令 → 进入工作台 → 点右上角头像 → 🔑 修改口令**。
3. 改密保存后会**自动退出到登录页**，这是刻意设计（用新口令重新验证一次），录制时可以顺带展示这个闭环。
4. 录制建议按 Tab 顺序走：**学情诊断 → 运动系统 → 体态实训 → 能力档案 → 肌骨沙盘 → 肌肉协作战队 → AI 伴学 → 教师端**，面包屑会跟着变，能直观体现「路径清晰」。
