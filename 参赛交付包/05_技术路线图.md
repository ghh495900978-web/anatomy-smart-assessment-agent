## 二、数据流向（融合闭环）

```
   单元学练 ──┐
              │  ① 作答 → 错误归因 A/B/C/D
              │  ② 映射 → L1/L2/L3（情境题可直打 L4）
              ├──────────►  统一六维能力档案  ──►  双向推荐
              │                                      │
   体态实训 ──┘  ① 五维解码 → 映射 L1 L2 L3 L5 L6    │
                 ② 风险分级 → 直打 L4 异常识别        │
                                                     ▼
                              测评薄弱 → 匹配体态区域（POSTURE_MODULES.systems）
                              能力短板 → 反推应补系统（SYSTEM_PRIMARY_COMP）
```

## 三、关键算法

| 算法 | 作用 | 位置 |
|---|---|---|
| `shuffleOptions` | 选项随机乱序并重映射正确答案，消除位置偏置 | app.js |
| `diagnose` | 判分 + 错误类型归因 + 模块聚合 + 图谱推荐 | app.js |
| `Mastery.update` | 指数平滑知识追踪，`m ← m + 0.4(obs − m)` | app.js |
| `compCredit` | 六维能力观测写入，`v ← v + 0.35(obs − v)` | app.js |
| `recommendPostureFromQuiz` | 测评薄弱 → 体态实训区域 | app.js |
| `recommendQuizFromPosture` | 能力短板 → 应补系统单元 | app.js |
| `migrateLegacy` | 两份历史档案合并迁移为统一档案 | app.js |
| `pmFallbackReport` | 大模型不可用时基于模板的五维报告兜底 | app.js |

## 五、技术选型理由

| 选择 | 理由 |
|---|---|
| 纯静态 / 零后端 | 无需服务器运维，学校无需采购，评审可即时访问，数据不出本机 |
| 原生 JS 而非框架 | 无构建步骤，代码可直接审计，评审专家可逐行查验算法公平性 |
| ECharts 5.4 | 国产开源，雷达/关系图能力强，中文文档完善 |
| OpenAI 兼容协议 | 学校可私有化部署，也可接国内任一合规大模型 |
| 本地检索兜底 | 断网、无密钥时核心教学功能不中断，保证课堂可用性 |
| localStorage | 学习数据保留在学生设备，天然满足数据脱敏与隐私保护要求 |
